# Developing the ROAR-NET API Generator

The user-facing [README](README.md) is the extension's Marketplace page; this file is for contributors.
Repository-wide setup (devcontainer, pnpm workspace, releases) is described in the
[root README](../../README.md).

## Setup

1. In VS Code: "Reopen in Container" (the devcontainer builds automatically; its `postCreateCommand` installs pnpm and runs `pnpm install` in the repository root)
2. Press `F5` → builds in watch mode and starts the extension in the "Extension Development Host" with the playground `../../playground/` as its workspace

## Structure

- `src/core/` – pure business logic, **no** import of `vscode`. Tested with Vitest (`pnpm test:unit`).
  - `src/core/model/` – metamodel code generated by TypeMF from `models/*.ecore` (`pnpm generate-models`); do not edit by hand.
- `src/infrastructure/` – encapsulates `vscode.*` access behind interfaces.
- `src/editors/` – the custom editor for `roar-net.config.json`; its UI lives in `webview-ui/`.
- `src/extension.ts` – entry point, wiring only (`activate`/`deactivate`).
- `test/unit/` – fast Vitest tests against `core/`.
- `test/e2e/` – runs the generator on a snapshot of the playground and compares with a golden copy (`pnpm test:update-golden` after intended changes).
- `test/integration/` – `@vscode/test-electron` setup against the real extension host (`pnpm test:integration`).

An ESLint rule (`no-restricted-imports`) enforces that `vscode` is only imported in `src/infrastructure/`, `src/editors/` and `src/extension.ts`.

## Important scripts

| Command                   | Purpose                                                                                   |
| ------------------------- | ----------------------------------------------------------------------------------------- |
| `pnpm watch`              | esbuild in watch mode (runs automatically on F5)                                          |
| `pnpm verify`             | Typecheck + lint + format check + unit tests (worth running before every commit)          |
| `pnpm test:integration`   | Starts a real headless VS Code (in the devcontainer: `xvfb-run -a pnpm test:integration`) |
| `pnpm test:update-golden` | Refreshes the golden copy of the end-to-end test                                          |
| `pnpm generate-models`    | Regenerates `src/core/model/` from `models/*.ecore`                                       |
| `pnpm package`            | Builds the `.vsix` file (only the files listed in `.vscodeignore` are shipped)            |
